Install

  1. Run the downloaded NordicLinks-Setup file. The installer is signed by Trond Erik Julseth, so Windows should show a verified publisher.
  2. Start Nordic Links. The setup guide asks for your license key, your microphone, and checks that it can see GSPro.
  3. Say “Caddie, what club” – the caddie answers.

The file is large (about 1 GB) because the speech model is included, so nothing has to be downloaded later. If you have an NVIDIA graphics card, the setup guide offers an optional speed pack (about 1.25 GB) that makes the caddie answer faster.

License

Your key looks like NL-XXXXXXXX-… and arrives by email after purchase. One key works on 2 PCs. To move Nordic Links to a new PC, open Settings and choose Deactivate this PC first (or free the PC in your Polar customer portal). Nordic Links checks the key online about once a day and keeps working for 14 days without internet.
